# ObGyne Chat

Asisten cerdas untuk ibu hamil – tanya apa saja seputar kehamilan, dapatkan tips, dan pantau perkembangan janinmu.

## Fitur Utama

- 💬 Chatbot pintar yang dapat menjawab berbagai pertanyaan seputar kehamilan dan kesehatan ibu
- 📅 Kalender kehamilan untuk menghitung usia kehamilan dan estimasi hari lahir
- 📖 Artikel edukatif tentang nutrisi, pertumbuhan janin, dan tips sehat selama hamil
- 🕒 Konsultasi 24 jam tanpa antre atau biaya tambahan
- 🔐 Data pengguna dijaga dengan aman dan rahasia

## Persyaratan Sistem

- Flutter SDK (versi >=3.0.0 <4.0.0)
- Dart SDK (versi terbaru)
- Android Studio / VS Code dengan Flutter plugin

## Instalasi

1. Clone repository ini:
```bash
git clone https://github.com/yourusername/obgynechat.git
```

2. Masuk ke direktori proyek:
```bash
cd obgynechat
```

3. Install dependencies:
```bash
flutter pub get
```

4. Jalankan aplikasi:
```bash
flutter run
```
